# Проверка TubobubaBot

## Автоматические проверки

```bash
npm test
npm run test:coverage
```

`npm test` запускает 30 проверок без Telegram-токена и без сети. Это функциональные тесты с реальным grammY `handleUpdate`, реальными обработчиками, очередью и временными файлами. На границах подменяются процесс скачивания и запросы Telegram API. Это не настоящая доставка в Telegram.

| Область | Проверяемое поведение |
| --- | --- |
| Сценарий YouTube | Ссылка → меню → выбранное качество → один `sendVideo` → очистка |
| Сценарий Instagram MP3 | Кнопка аудио → извлечение MP3 → `sendAudio` |
| Выбор качества | Все альтернативы формата соблюдают верхнюю границу разрешения |
| Меню | Отмена, истечение срока, повторный клик, некорректная кнопка |
| Изоляция | Два пользователя, один пользователь в двух чатах, поздний ответ старой ссылки |
| Очередь | Максимум два задания, порядок ожидания, позиция владельца, освобождение слота после ошибки |
| Размер | Границы 50 МБ и 2000 МБ, цельный файл 60 МБ в локальной политике, отказ без разрезания |
| Восстановление | После превышения лимита работает новое меню с выбором аудио |
| Ошибки | Сбой получения информации, скачивания, отправки, редактирования и удаления статуса |
| Файлы | Удаление частичных файлов и промежуточных потоков; файл существует во время отправки |
| Процесс | Исполняемый файл с пробелами в пути, аргументы без shell, полезная диагностика |
| Ссылки | Точные границы доменов, запрет поддельных доменов, скрытая ссылка после emoji |
| Повторы | Ограниченные повторы временных ошибок; отсутствие повторов для требования входа |

Большие файлы в тестах созданы через sparse-файлы. Они проверяют политику размера и очистку, а не реальную отправку гигабайтов через сеть. Coverage помогает находить пропущенные ветки и не заменяет проверку поведения.

## Ручной сценарий

Перед тестом остановите другую копию бота. Выполните `npm start`; для разработки можно использовать `npm run dev` (встроенный Node.js watch).

1. В личном тестовом чате отправьте `/start`: должно появиться понятное приглашение без `undefined`.
2. Отправьте публичный Instagram Reel, выберите «Лучшее качество». Дождитесь одного видео; откройте его и проверьте воспроизведение. Меню и статус должны исчезнуть, видео — остаться.
3. Отправьте ту же ссылку, выберите «Только аудио (MP3)». Во время загрузки отправьте `/queue`: бот должен ответить, не ожидая окончания скачивания. Запустите полученную аудиодорожку.
4. Отправьте короткое YouTube-видео, выберите 240p или другой доступный вариант. Проверьте доставку одного видео. Выбор — верхняя граница разрешения, без искусственного увеличения исходника.
5. Отправьте новую ссылку и нажмите «Отмена». Файл не должен скачиваться, меню должно исчезнуть.
6. Для проверки превышения 50 МБ используйте тестовый длинный ролик. Должны появиться объяснение и новое меню, без отправки отдельных частей. Этот сценарий не требует намеренно скачивать гигабайты на каждой проверке: детерминированные тесты покрывают обе границы размера.
7. Остановите тестовый процесс через Ctrl+C. Существующие cookies не нужны для проверенных публичных ссылок; при сетевом тесте использовались новые пустые Netscape cookie-файлы.

## Результат проверки 2026-10-10

Бот: `@tubobuba_bot`, личный чат пользователя, проверка разрешена пользователем.
Клиент: Telegram macOS для ввода `/start` и первой ссылки; Telegram Web для кнопок и воспроизведения (нативный клиент не предоставил доступные инструменту кнопки).

- `/start`: ответ получен.
- Instagram `https://www.instagram.com/reel/DdOyq0Vxhs6/`: меню появилось, видео доставлено одним сообщением, открыто в плеере и воспроизводится.
- Та же ссылка, MP3: аудио доставлено с длительностью 2:49; плеер запущен, время дошло до 0:03, воспроизведение остановлено.
- `/queue` во время скачивания: ответ «Скачивается: 1/2», «В очереди: 0», «Ваш файл обрабатывается».
- YouTube `https://www.youtube.com/watch?v=jNQXAC9IVRw`: меню всех настроенных разрешений появилось; выбран вариант 240p, доставлено одно видео длительностью 0:19, открыто и воспроизведено в плеере.
- Отмена новой ссылки YouTube: получено «Скачивание отменено.», меню удалено, новый файл не отправлен.
- Тестовый процесс остановлен через Ctrl+C. Временные файлы скачиваний очищены; два созданных для проверки пустых cookie-файла удалены.
- Автотесты: 30/30 прошли.
- Зависимости: после удаления nodemon `npm audit` — 0 уязвимостей.
- Навыки `backend`, `frontend`, `qa`: официальный `quick_validate.py` — все три валидны.

Не проверялись вручную: TikTok, закрытые публикации, реальные загрузки через собственный Bot API и доставка файла 2000 МБ. Локальный сервер Bot API в этой задаче не разворачивался.
